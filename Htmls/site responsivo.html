Relatório de Desenvolvimento do Site Responsivo

Introdução

Este projeto tem como objetivo desenvolver um site responsivo que se adapta a diferentes tamanhos de tela, como celulares, tablets e desktops. Buscamos oferecer uma navegação intuitiva, moderna e agradável visualmente, utilizando técnicas como Flexbox, CSS Grid e Media Queries.

Desenvolvimento

A estrutura do site foi construída com HTML semântico, utilizando elementos como <header>, <nav>, <main> e <footer>. Para o layout dos posts recentes, optamos pelo uso do CSS Grid, que proporciona uma organização dinâmica dos elementos na tela.

A responsividade foi aplicada com Media Queries, que ajustam o layout de acordo com o tamanho da tela. As principais quebras são:

  • Mobile (até 600px): Layout em coluna, menu simplificado e imagens ajustadas.
  • Tablet (601px a 900px): Grid com duas colunas e espaçamentos maiores.
  • Desktop (acima de 901px): Grid com três ou mais colunas, sidebar e maior aproveitamento do espaço.

Também foram adicionadas transições suaves em botões e links para uma melhor experiência do usuário, além de variáveis CSS para facilitar a manutenção das cores, fontes e espaçamentos.

Conclusão

O desenvolvimento deste site proporcionou uma compreensão prática sobre como criar layouts responsivos e modernos. A junção de Flexbox, Grid e Media Queries foi essencial para garantir que o site se comporte bem em diferentes dispositivos. Esse projeto reforçou a importância de um design bem planejado, acessível e funcional.

Tabela de Recursos Utilizados
